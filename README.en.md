# cairn

> Every pit we fell in, marked for the next.

🌏 [中文](README.md) | English

A field guide for **indie developers shipping apps in mainland China**: ICP filing, the App filing (required since 2023), Apple Developer organization account, code signing and notarization, App Store review, in-app purchases and subscriptions, Android/HarmonyOS stores, SMS signatures, domains and HTTPS.

Official docs tell you the rules. This repo tells you what actually happened: the steps, how long each one really took, what to prepare, and the pits we fell into — every note dated, because the rules keep changing.

The content is in Chinese, since these processes only matter to developers shipping in China. Three things worth knowing even if you don't read Chinese:

1. The **App filing** (App 备案) is the slowest step (5–25 working days). Start it before your code is done.
2. Your **App Store name must match the filed name exactly**, character for character, or App Store Connect will refuse to ship to mainland China.
3. A **brand-new app** needs five things before "Add for Review" works: primary category, content rights, age rating, price, and availability (empty by default, not worldwide).
