# 犹记 YouText：改名、备案名对不上、先去掉中国大陆提交

> 一个个人记忆 App，iPhone 和 Mac 同一条 App Store 记录，带一个非消耗型内购和两档订阅。同一个公司主体的第二个 App。

| 日期 | 事件 |
|---|---|
| 11-02 | 定名，准备备案底稿 |
| 11-08 | App Store Connect 建记录占名（iOS + macOS 同一条）；**提交 App 备案** |
| 11-10 | 发现商标已被他人注册，**产品改名**。备案还在审，填的是旧名 |
| 11-10 | App Store Connect 保存新名字的中文部分，报「名称已被使用」（被别人的未上架记录占了），只好存成「中文名 + 英文名」 |
| 11-11 | **备案通过**（提交后 3 天），名称还是旧名；之后申请名称变更，改成单独的中文名 |
| 11-17 | 隐私标签、App 合规声明、审核备注等填好；因为改名变更还没批，**暂停提交** |
| 11-18 | 名称变更批下来；定价方案改成订阅，新建订阅群组 |
| 11-18 夜 | 统一版本号（工程 1.0.0 → 1.0）；打正式包时才发现调试版专用代码被正式代码引用，补上后上传成功 |
| 11-19 00:18 | 提交审核时被拦：「App 名称与 ICP 备案号相关联的工信部记录不符」——备案名是单独的中文名，商店名是「中文名 + 英文名」。**去掉中国大陆，先提交其余 174 个地区** |

## 回头看

- 根本原因在改名那一步：新名字没在商店里先保存成功，就拿去办了备案变更，结果商店只能存「中文名 + 英文名」，两边错开。正确顺序见 [这篇](../pitfalls/app-name-must-match-filing.md)。
- 新 App 第一次送审，一口气撞上了五样首次必填、订阅群组要单独加进草稿、版本号不一致、Release 编不过。这些都整理进了 [首次送审清单](../checklists/app-store-first-submission.md)。
- 中国大陆区等备案名再变更一次，批下来后在「管理供应情况」勾回来即可，不用重新送审。
