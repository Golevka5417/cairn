# cairn · 过来人

> Every pit we fell in, marked for the next.
> 我们踩过的坑，垒成后来人的路标。

cairn 是登山的人在岔路口垒起的一小堆石头：前面的人走过，留个记号，后面的人就不用再猜。

这个仓库记的是**国内独立开发者在代码之外要走的流程**：备案、开发者账号、证书签名、App Store 上架、内购订阅、安卓鸿蒙商店、短信签名、域名 HTTPS。官方文档只写规则，不写要等多久、哪一步会卡、哪里填错了要返工。这里只写亲手走过的：步骤、实际花的时间、要准备的材料、踩过的坑。

🌏 中文 | [English](README.en.md)

## 为什么做

我一个人做了两个 iOS App（只此一橘、犹记 YouText），2026 年 10～11 月从零走完了备案和上架。每次走流程都要从头查，查到的还常常是过时的帖子。踩完一遍之后发现：真正耽误时间的不是规则本身，而是**顺序**和**细节**——哪件事要最先开、哪个名字要一字不差、哪一页默认是空的。

这些记在私有笔记里只能帮到自己，所以脱敏后公开出来。

## 先看这里：一个 App 从零到上架

```
公司主体 ──► 已备案的网站域名（ICP 备案，1～3 周）
                │
                ├──► 苹果开发者账号·组织（1～10 天，要能访问的官网）
                │
                └──► App 备案（5～25 个工作日，最慢，最先开）
                          │
   ASC 建记录、先占名 ────┤  ← App 名称必须和备案名一字不差
                          ▼
              隐私政策页 + 截图 + 内购 ──► 首次送审 ──► 上架
```

**最重要的三句话**

1. **App 备案最慢**，代码还没写完就该交。
2. **名字先在 App Store Connect 占住，再拿同一个名字去备案。** 差一个字，中国大陆区交不了。
3. **备案一次填到位**：将来一年要上的平台、支付、语言、域名现在就写进去，不然每加一样就是一轮 5～25 个工作日的变更。

## 耗时速查（2026 年 10～11 月实测）

| 流程 | 实际耗时 | 费用 | 状态 |
|---|---|---|---|
| 苹果开发者账号（组织） | 提交次日通过 | 688 元/年 | 实测 |
| 网站 ICP 备案 | 1～3 周 | 免费 | 实测 |
| App 备案 | 一次 10 天，一次 3 天（自然日） | 免费 | 实测 |
| App 备案改名变更 | 一周左右（提交日没精确记） | 免费 | 实测 |

| 公安联网备案 | 约 1～2 周 | 免费 | 未走完 |
| 算法备案 / 大模型登记 | 第三方口径 3～4 个月 | 官方免费 | 未实测 |

## 怎么读

- 每条经验后面都有日期，比如「（2026-11 实测）」。**规则会变**，日期越旧越要自己再核一遍。
- 标「未实测」的是二手信息，只当线索。
- 本人的情况：一人公司主体做 App，服务器和备案在腾讯云，开发者账号是组织账号。个人主体、其他云服务商的细节可能不同。
