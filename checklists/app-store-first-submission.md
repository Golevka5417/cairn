# App Store 首次送审前必填项

> 新 App 第一次「添加以供审核」前对一遍。2026-11-19 实测，缺任何一样都会报错或保存不上。

## App 信息

- [ ] 名称和 App 备案名一字不差
- [ ] 备案号已填（末尾带 A）
- [ ] 主要类别
- [ ] 内容版权
- [ ] 年龄分级问卷（7 步；没有对应功能就全选「否」→ 4+；内嵌网页打开任意链接会变 18+）
- [ ] 顶部如果有「确认信息」（提供商名称与备案主体名不符），由账号持有人确认

## 价格与销售范围

- [ ] 定价：免费也要点「添加定价」选 0 元
- [ ] 供应情况：默认是空的，手动选地区

## App 隐私

- [ ] 隐私政策网址
- [ ] 隐私标签填完并点了「发布」

## App 合规（中国大陆）

- [ ] 两条声明（安全评估、AIGC）已填

## 版本页

- [ ] 版本号和工程 `MARKETING_VERSION` 完全一样（1.0 ≠ 1.0.0）
- [ ] 截图：「带灵动岛的 iPhone（中等显示屏）」1206×2622 或 1179×2556
- [ ] 描述、关键词、技术支持网址、版权
- [ ] 审核联系人四项（不填，描述和审核备注保存不上）
- [ ] 审核备注：有付费页、演示账号、特殊入口的写清楚怎么到达
- [ ] 发布方式：审核后自动发布 / 手动
- [ ] 已选构建（新包上传后要刷新页面才出现）

## 内购和订阅

- [ ] 每个内购商品有一张审核截图
- [ ] 内购和 App 版本在**同一份草稿**里
- [ ] 订阅群组本身也点了「添加以供审核」
- [ ] 有自动续订：**每个语言**的描述里放了使用条款（EULA）链接（2026-11-19 被自动退回过，见 [这篇](../pitfalls/subscription-needs-eula-link.md)）
- [ ] App 内付费页：价格、周期、自动续订说明、恢复购买、使用条款和隐私政策链接

## 包

- [ ] 用 Release 配置编过一遍
- [ ] 扩展（小组件等）版本号跟主 App 一致
- [ ] 用了 CloudKit 的，结构已部署到 Production
- [ ] Xcode 苹果账号在线
- [ ] Mac 版：entitlements 里每个权限都有对应功能；用了 `network.server` 的在审核备注里点名写清楚（见 [这篇](../pitfalls/mac-network-server-entitlement.md)）
